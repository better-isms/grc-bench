# Contributing

Report a wrong task or answer key in an issue, citing the task id and the official source.

Outside pull requests are read line by line. At v0.1 we accept no change to dependencies, install scripts or workflows.

## Rules for Better ISMS staff and agents

- Do not tune ISMS Copilot's framework knowledge, prompts or routing on benchmark tasks.
- Do not use ISMS Copilot or its knowledge to write tasks or answer keys.
- Do not open an ISO or AICPA standard while writing or reviewing a task or key.
- No customer data or customer wording.
